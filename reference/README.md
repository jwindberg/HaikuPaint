# reference/

Put the downloaded MacPaint and QuickDraw source from the Computer History
Museum here (search computerhistory.org for "MacPaint and QuickDraw Source
Code"). Everything in this folder except this file is git-ignored, because
the CHM license allows study but not redistribution.

Use it to understand behavior and algorithms. Write HaikuPaint's code fresh.
Do not translate or paste it. See `docs/REFERENCES.md`.
