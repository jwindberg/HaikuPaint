# References

## The original
- **MacPaint and QuickDraw source code** at the Computer History Museum
  (2010). Search computerhistory.org for "MacPaint and QuickDraw Source
  Code". Download it into `reference/`, which git ignores.
  - License: CHM's non-commercial license, which allows study but not
    redistribution. **Rule for this project:** read it to understand
    behavior and algorithms, then write new code. No line-by-line
    translation, and no pasting of its code or comments.
- **folklore.org**: Andy Hertzfeld's stories of the original Mac team,
  including several about MacPaint and Bill Atkinson.
- **Inside Macintosh, Volume I**: QuickDraw (patterns, pens, transfer
  modes, regions) and the Toolbox UI conventions. Scans are easy to find
  online.
- **Mini vMac** or **Basilisk II** with System 1–6 and MacPaint, to compare
  behavior side by side. Check `pkgman search` for Haiku ports.

## Haiku development
- **Haiku Book** (API reference): https://www.haiku-os.org/docs/api/
- **The Be Book** (the classic API docs, still mostly accurate):
  https://www.haiku-os.org/legacy-docs/bebook/
- **Haiku coding guidelines**:
  https://www.haiku-os.org/development/coding-guidelines
- **makefile-engine**: documented in the template at
  `/boot/system/develop/etc/makefile` on Haiku.
- **Example apps worth reading**: Haiku's own `src/apps/` (for example Icon-O-Matic
  and ShowImage) and WonderBrush, a Haiku-native paint and vector app.
- Forums: https://discuss.haiku-os.org
